# Inflow

[English](README.md) | **简体中文**

Inflow 是一款围绕一个核心学习循环构建的韩语学习桌面应用：

```text
媒体 → 听力 → 词汇 → 生成内容 → 词汇
```

导入韩语音频或视频，逐句进行练习，只在需要时显示适量的原文或翻译，在原始语境中收集陌生词汇，并将选中的词汇重新用于生成个性化的韩语阅读短文。

项目目前面向 Windows 上的个人使用。桌面端已经可以直接从仓库运行；将其打包为可独立安装、自包含的应用仍属于后续工作。

## 我能用它做什么？

Inflow 帮助你把韩语音频和视频变成一个主动学习流程：

- 逐句听取媒体内容，只在需要时显示韩语原文或中文翻译；
- 收集和管理陌生词汇，并保留每个词汇对应的来源和学习语境，无论它来自媒体还是生成内容；
- 使用正在学习的词汇生成个性化韩语阅读短文；
- 从生成的短文中发现新词汇，并继续整个学习循环。

语音识别、翻译和生成内容都用于辅助学习，而不是权威答案。

## 配置 LLM API Key

Inflow 使用 DeepSeek 提供按需的上下文中文翻译、生词语境释义，以及根据选中词汇生成韩语阅读短文。使用这些功能前，请在系统环境、`.env` 或 `.env.local` 中配置 `DEEPSEEK_API_KEY`。

项目有意将 LLM 的使用范围控制得很小，以尽可能减少 token 消耗。翻译和生词查询只会在用户明确操作时发起，只发送完成当前任务所需的少量上下文，并复用已经成功获得的结果，避免重复请求。语音识别、句子分组、韩语词形分析和词典查询仍在本地完成；生词查询会优先使用内置韩中词典，只有用户明确请求时才调用 LLM。

## 运行桌面应用

当前开发环境使用 Node.js、Electron、Python 3.12 和本地处理模型。在 Windows 上，首先准备本地 Python 和模型环境：

```powershell
.\scripts\setup_windows.ps1
npm ci
```

然后构建并启动桌面应用：

```powershell
npm run desktop:build
npm run desktop:start
```

本地处理使用 `.models/` 下的资源，以及 `.venv-win/` 下的 Windows Python 环境。这些目录不会提交到 Git。
